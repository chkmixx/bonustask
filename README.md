This project implements Dijkstra’s Algorithm in Java.

The algorithm finds the shortest path from a starting vertex to all other vertices in a weighted graph.

Features
- Weighted graph representation
- Distance array
- Visited array
- Shortest path calculation

 Complexity
Time Complexity: O(V^2)

 How It Works
1. Initialize distances
2. Select vertex with minimum distance
3. Update neighboring vertices
4. Repeat until all vertices are visited

 Output Example
Vertex 0 Distance = 0
Vertex 1 Distance = 3
Vertex 2 Distance = 1
Vertex 3 Distance = 8
